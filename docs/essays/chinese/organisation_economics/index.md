# 组织经济学

## 生产力如何被组织、调用与承接

星衡｜Aster Vale · Longview Archive｜观势档案

**定位：**《文明结构算法》提供组织形式的历史生成骨架；本书提供同一物质生产循环的经济运行说明。中国与西方历史路线在此不再分卷。其他文章是从具体机制向现实问题展开的投影，不是新增一套上位理论。

**一句话：**生产力不只是能够造出来；还要调得到、卖得出、用得起，并在失败后重新开始。

**人的位置：**生产力不能绕开能够长期劳动、学习、协作并传递经验的人。第01章简要说明生产要求如何传递为人的持续投入，第06章说明这种投入为什么必须有生活与能力的承接。神话、文化史及现代工业化的人力准备，作为不同专题分别展开，本书不另设历史专章。
