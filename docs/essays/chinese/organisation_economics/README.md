# 组织经济学｜本地正本说明

本目录是一份完整的中文工作稿，各章均为独立 Markdown。请先整体审稿，再决定怎样拆为公开站点的网页。**当前不自动修改 `mkdocs.yml`、`build_corpus.py` 或既有 git 文件。**

## 三层分工

- 《文明结构算法》：历史生成骨架；中国卷与西方卷各自保留。
- 《组织经济学》：共同经济运行说明书；不再分中国、西方两卷。
- 各种投影文章：从一个机制进入具体事件、刊物、读者和证据。

## 人的内压与专题分工

- 说明书第01章仅定义“内部再生产压力如何落实到人”，第06章连接持续投入与人的生活承接；**不新开中国／西方人力比较章节**。
- 中国长期历史与精神文化的专题：以神话中的做功、神明的职掌、人与神之间的往复关系、儒家伦理与家庭责任为研究对象；它检验文化怎样表达并传递持续做功的要求，不与现代工业化合为一篇。
- 已有《中国工业化的人力架构》系列：只回答中国现代工业化为什么能够快速展开，重点是近代至改革开放前后的人口重组、教育卫生、知识扩散、工厂训练与外资调用此前形成的人力基础。
- 未来《西方工业化的人力准备》：独立研究西方在工业化以前及工业化过程中怎样形成、训练并复制工业人口；不插入中国长期文化篇，也不把中国系列改写为东西方比较。
- 以上专题均是从说明书投影出去的具体历史研究；不因此回头改变《文明结构算法》两卷的任务。

## 源文件与构建产物

`index.md`、`阅读与校验规则.md`、`核心术语.md` 和 `00-*.md`—`10-*.md` 是独立源文件。执行 `python build_organisation_economics.py` 后，只在**本目录上一层**生成 `_组织经济学_中文完整合订本.md`；开头的下划线说明它是内部审稿产物，不要作为另一份正本进入 corpus 或网站。

编辑时只修改独立章节，重新 build；不要在合订本直接修改。文件名固定编号；修改正式标题可改 H1，不必改变路径。后续如果进入网站，建议将这组文件放在 `docs/essays/chinese/organisation-economics/`，但这是建议路径，不在本次交付中生成或激活 YAML 导航。

## 内容边界

本书依据已完成的《文明结构算法》展开统一经济问题；不同组织方向的历史生成属于骨架，这里只解释进入同一生产循环后的实际机制。全球化讨论是有条件的反馈分析，不是对国家未来的确定性预言。宏观数据、史实注释和个别政治经济判断需要在后续投影发表稿中逐项校对。
