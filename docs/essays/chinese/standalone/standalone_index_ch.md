# 独立短文

“独立短文”收录可以单独成立的文章。

它们通常从一个人人熟悉的现象出发，只追踪一个有限的问题，直到一个更深的结构性问题自然出现。

这里的文章**不是连续系列**，也不要求读者预先了解 Longview Archive 的理论框架。每一篇都应当能够独立阅读、独立闭合。

这里只公开少量经过筛选的文章。它们的目的不是一次讲完整套理论，而是把一个问题讲清楚，把一条因果线走完，然后停在下一个问题开始的地方。
